# 🤖 Animal Classification & Sentiment Analysis AI Project

A comprehensive AI-powered web application built using **Python, Flask, TensorFlow/Keras, and Natural Language Processing (NLP)**. The system provides automated image recognition for animal classification along with sentiment analysis models.

## ✨ Key Features

- **🐾 Animal Classifier:** Machine learning model trained to classify animal species from user-uploaded images.
- **💬 Sentiment Analysis Engine:** Text processing pipeline utilizing sentiment dataset (`.csv`) for analytical scoring.
- **🌐 Dynamic Web Interface:** Flask frontend with template rendering and custom CSS styling.

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **AI / ML Frameworks:** TensorFlow, Keras, NumPy, Pandas
- **Frontend:** HTML5, CSS3 (Flask Jinja Templates)
